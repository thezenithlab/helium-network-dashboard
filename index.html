⚠ Data Limitation — Post-Solana Hotspot Deaths
The Helium Solana entity manager records onboarding events only — there is no on-chain “death” or deactivation instruction. Post-Solana hotspot churn cannot be recovered from blockchain data. The only available proxy is the oracle active_iot_devices snapshot delta (2 data points: Apr 7 → Apr 20, 2026: 207,332 → 204,389 = −2,943 net), which will grow at 1 point per day via the daily scraper. IoT cumulative registrations (from --mode iot --backfill scan, pending) will enable a lifetime-registered minus active calculation once available.
